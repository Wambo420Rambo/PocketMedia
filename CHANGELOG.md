# Changelog

## 1.1.0 (2026-10-22)

- Add media: **Download from Twitter**. Paste one or more post links (twitter.com or x.com); their pictures (original size), videos and GIFs are downloaded, shown in the usual review list, and added to Pictures, Videos and GIFs. Twitter's GIFs are turned back into .gif files. This is the only feature that uses the network.

## 1.0.0 (2026-10-16)

The first release.

- Quick popup on a global shortcut (Win + Alt + . by default, changeable in Settings), placed near the text cursor.
- Search by file name: every word must appear, in any order. Filters for GIF, Picture and Video, plus All media and Recently used lists; the popup always opens on All media.
- Paste the original file into the app you were in with a click or Enter, or drag it out as a copy.
- Tiles carry a type badge (GIF, Picture, Video) and show the name without its extension.
- GIFs loop while visible; videos can preview on hover (or not at all).
- Add media from files, a folder with its subfolders, or by dropping them. A review list lets you rename files first. Duplicates are skipped and nothing is ever overwritten. Your originals stay where they are.
- Manager: browse, sort, rename, open the folder, move to the Recycle Bin.
- Follows changes made in the Media folder with File Explorer.
- Back up library to a folder you choose, with checked copies.
- Two profiles: Use less memory or Open faster.
- Autostart quietly into the tray.
- Installer without admin rights, for Windows 11 x64. Updates keep all media and settings.
- Uninstaller that asks you to type CONFIRM before it deletes the Media folder, and offers a backup first.
- No network access, no telemetry, no update check.
